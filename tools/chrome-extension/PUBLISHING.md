# ストア公開手順（Chrome Web Store / Edge Add-ons）

この拡張「nyan Real Audio Wall connector」を Chrome ウェブストア・Microsoft
Edge アドオンに公開するための手順とチェックリストです。英語版は
[PUBLISHING.en.md](PUBLISHING.en.md)。

## 1. アップロード用 zip を作る

リポジトリのルートで:

```powershell
.\package-chrome-extension.ps1
# -> dist\chrome-extension-<version>.zip
```

`manifest.json` が zip のルートに来る形（ストア要件）で、`README.md` や
`PUBLISHING*.md` などのドキュメントは除外されます。バージョンは
`manifest.json` の `version`（現在 0.3.0）から取得されます。

## 2. 必要なアセット

| 用途 | サイズ / 形式 | 必須 |
| --- | --- | --- |
| ストアアイコン（掲載用） | **128 × 128 PNG** | 必須 |
| スクリーンショット | 1280 × 800 または 640 × 400 PNG/JPEG（1枚以上） | 必須 |
| 小プロモタイル | 440 × 280 PNG | 任意 |
| マーキープロモ | 1400 × 560 PNG | 任意 |
| 拡張内アイコン（`manifest.json` の `icons`） | **128 PNG 1枚で可**（任意） | 任意 |

- ストアアイコンは **128 × 128**。タスクトレイアイコン（16〜32px）より大きい
  ので、同じ猫＋AR デザインを 128px で書き出してください。
- **拡張内アイコンは必須ではありません**。`icons` 未宣言でも動作・公開は可能
  で、その場合ストア掲載アイコンはダッシュボードでアップロードした 128px が
  使われます。
- 付けるなら **128px 1枚で十分**です（Chrome が他サイズへ自動リサイズ）。
  この拡張はツールバーボタン（action）が無いので、実際に効くのは 128
  （インストール / ストア）と、あれば 48（`chrome://extensions` 管理ページ）
  くらい。複数を宣言するのは「各 UI でボケない」品質目的の任意対応です:

  ```json
  "icons": { "128": "icons/128.png" }
  // 品質を上げたいなら "48": "icons/48.png", "16": "icons/16.png" も追加
  ```

## 3. Chrome ウェブストアに公開

1. [デベロッパー ダッシュボード](https://chrome.google.com/webstore/devconsole)
   にアクセス（初回のみデベロッパー登録 $5・一回限り）
2. **新しいアイテム** → 手順 1 の zip をアップロード
3. **ストアの掲載情報**: 名前・説明（`_locales` の `ext_name` / `ext_desc`
   が反映）・カテゴリ（「ツール」など）・言語（en / ja）・アイコン・
   スクリーンショットを設定
4. **プライバシー** タブ: 下記「権限の説明」を記入し、データ使用と
   プライバシーポリシー URL を設定（第5・6節）
5. 公開対象（一般公開 / 限定公開）を選び **審査に送信**

> 掲載名・説明文は OBS 版・単独版（Spatial Wall）どちらでも通じる中立な表現に
> してあります（`_locales/*/messages.json`）。文言を変えたら zip を作り直して
> アップロードしてください（拡張名はブランドとして全言語共通）。

## 4. Microsoft Edge アドオン（任意）

同じ zip を [Partner Center](https://partner.microsoft.com/dashboard/microsoftedge)
にアップロードできます（Chromium 拡張なので共通・登録無料）。掲載情報・
スクリーンショットは別途必要です。

## 5. 権限の説明（審査用・コピペ可）

ダッシュボードの「権限の正当性」に貼り付けられる説明です。

- **host_permissions `<all_urls>` / content script（全 URL）**:
  ユーザーが空間化したい任意サイトのタブで `<audio>/<video>` をフックして
  音声を取り込むため。対象サイトを事前に限定できない。
- **`tabs`**: 多重化した音声ストリームをタブ単位で識別・ラベル表示する
  ため（タブのタイトル）。
- **`system.display`**: ウィンドウのオンスクリーン位置をモニタ配置に
  マップし、空間定位の方向を決めるため。
- **`storage`**: 接続ポート番号などのユーザー設定を保存するため。
- **リモートコード**: 使用しない（同梱スクリプトのみ）。

## 6. プライバシー / データの取り扱い

- 音声 PCM とウィンドウ位置メタデータは **ローカルの `ws://127.0.0.1:<port>`
  にのみ送信**します。外部サーバーへの送信・解析・トラッキングは一切
  ありません。
- 保存するのは接続ポート番号のみ（`chrome.storage.sync`）。
- Chrome ウェブストアは `<all_urls>` 等の権限に対しプライバシーポリシー
  URL を要求します。「個人データを収集せず、音声はユーザーの PC 内
  （localhost）のアプリにのみ送る」旨を明記した簡単なページで構いません。

## 7. 更新（バージョンアップ）

1. `manifest.json` の `version` を上げる（例 0.3.0 → 0.3.1）。WS プロトコルの
   互換性ルールは本リポジトリの CONTRIBUTING を参照
2. `.\package-chrome-extension.ps1` で zip を作り直す
3. ダッシュボードの既存アイテムに新しい zip をアップロードして再送信

> 拡張の正本はこの `tools/chrome-extension/` です。単独版アプリには同梱
> コピーが入りますが、ストア公開は常にこの正本から行ってください
> （コピー側を編集するとドリフトします）。
